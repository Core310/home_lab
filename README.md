# FOSS Anime Homelab Stack

Welcome to the ultimate Infrastructure-as-Code (IaC) media server deployment! This repository contains the automation required to spin up a fully isolated, robust, and automated media pipeline on your homelab. 

## What This Does

This setup transforms a bare linux machine into a fully functional media server, complete with network-wide ad-blocking and an automated acquisition pipeline. It utilizes **Ansible** as the provisioner and **Podman** (with podman-compose) as the lightweight, daemonless container engine.

The stack deploys the following isolated services:
- **Pi-hole**: Network-wide ad blocking and local DNS resolution (crucial for Tailscale MagicDNS routing).
- **qBittorrent**: The torrent downloader, strictly isolated to drop raw files in a designated download folder.
- **Prowlarr**: The indexer manager that searches the web for media and automatically syncs indexers to Sonarr.
- **Sonarr**: The TV show manager. It acts as the brain—searching for shows, grabbing torrents, sending them to qBittorrent, and ultimately organizing the finished files.
- **Jellyfin**: The FOSS media streaming server. It acts as your personal Netflix, scanning the final organized media folder to serve directly to your devices.

## How It Works: Ansible vs. Podman

**You only need to run the Ansible playbook.**

Here is what the Ansible playbook (`site.yml`) automates for you:
1. **Installs Prerequisites:** It automatically ensures `podman` and `podman-compose` are installed on the host.
2. **Scaffolds the File System:** It creates the exact directory structures required on the host (`/opt/media`, `/opt/media/downloads`, `/opt/media/jellyfin`) with the correct user permissions (`1000:1000`) so the Podman containers can read and write without access denied errors.
3. **Deploys the Code:** It creates the deployment folder (`/opt/foss_stack`) and copies your `docker-compose.yml` into it.
4. **Spins Up the Stack:** Finally, Ansible executes the `podman-compose up -d` command for you. 

When the playbook finishes running, your entire infrastructure is online and humming.

## Deployment Instructions

Execute the Ansible playbook directly against your local host:

```bash
ansible-playbook -i localhost, -c local site.yml --ask-become-pass
```
*(The `--ask-become-pass` flag prompts for your sudo password, which Ansible requires to install Podman and create root-level directories in `/opt/`).*

## Post-Deployment Wiring

Once the infrastructure is spun up, the containers still need to be securely exposed to your mesh network and introduced to one another (e.g., handing Sonarr's API key to Prowlarr).

Please refer to the `gsd-post-deployment-plan.md` artifact generated by the AGY AI for the step-by-step UI wiring and Tailscale MagicDNS networking rules. This will show you exactly how to route all your traffic securely through Pi-hole and automate the zero-touch media pipeline.
